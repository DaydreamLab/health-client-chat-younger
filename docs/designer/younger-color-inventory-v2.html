怎麼用這份檔

這是客人端 app v2 現行配色。舊版封存在 younger-color-inventory.html，兩份可並排對比。雙擊用瀏覽器開啟即可。上方切換會讓「元件預覽」跟這份文件的底／字色跟著日間／夜間變。

換色只交 600 錨點。 工程跑 pnpm colors:ramps 生成 50–950，再改 app/assets/css/main.css。不要逐頁改元件。 彩色主色日間 600、夜間自動亮化成 400。標了「色階外」的 hex 不會跟著 mist 色階自動變。

600 → 11 階 + 夜間映射

每個 600 對白做 tint、對黑做 shade。彩色用舊 brand 混色比例；Neutral 用舊 mist 比例。夜間不另做色票，只換階。

色階 50–950

Nuxt UI 對應：brand → primary、mist → neutral、forest → success、sand → warning、coral → error、lagoon → info。有外框的 step 是畫面有直接用到的；其餘仍要保留給 hover／元件庫。點色塊可複製 hex。

brand · primary

直接用到：600 日間主色、400 夜間主色、700／300 主按鈕 hover、300／500 disabled。

mist · neutral

直接用到：50／100／200 日間底與邊；400／500／600 字色；800／900／950 夜間底與邊。夜間正文用 50。

forest · success

直接用到：日間 600、夜間 400 指標「正常」字色；未上線 started badge 用 500／700。

sand · warning

直接用到：日間 600、夜間 400 指標「偏低」字色。

coral · error

直接用到：日間 600、夜間 400 登入錯誤與指標「偏高」字色。

lagoon · info

直接用到：日間 600、夜間 400；方案視覺區 radial 仍用 info-500。
