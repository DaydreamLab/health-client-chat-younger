怎麼用這份檔

這是客人端 app 現在實際在用的顏色，不是設計稿。雙擊用瀏覽器開啟即可，不必安裝任何軟體。上方切換會讓「元件預覽」跟這份文件的底／字色跟著日間／夜間變。同資料夾的 CSV 可貼進 Figma 或 Excel。

換色請回填 hex 或整條色階。 工程會改 app/assets/css/main.css 的 token，不要逐頁改元件。 語意色（--ui-bg、--ui-primary 等）優先；色階 50–950 請整組給，Nuxt UI 會用中間色。 標了「色階外」的 hex 不會跟著 mist 色階自動變。

語意色 換色優先

畫面幾乎都吃這層。Tailwind class 如 bg-default、text-highlighted 對應這裡，不是直接寫 mist-50。

色階 50–950

Nuxt UI 對應：brand → primary、mist → neutral、forest → success、sand → warning、coral → error、lagoon → info。有外框的 step 是畫面有直接用到的；其餘仍要保留給 hover／元件庫。點色塊可複製 hex。

brand · primary

直接用到：600 日間主色、400 夜間主色、700 日間主按鈕 hover、300 夜間主按鈕 hover。

mist · neutral

直接用到：50／100／200 日間底與邊；500／600 日間字；800／900／950 夜間底與邊。

forest · success

直接用到：指標「正常」字色；未上線的 started badge 用 500／700。

sand · warning

直接用到：指標「偏低」字色。

coral · error

直接用到：登入錯誤、指標「偏高」字色。

lagoon · info

直接用到：方案視覺區 radial（info-500）。
