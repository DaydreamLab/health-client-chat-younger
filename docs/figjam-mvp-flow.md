## 本專案範圍（A 客人端）

- 入口、有沒有血檢報告、選方案、金流、預約、交給顧問
- 逛首頁／方案可不登入；交給顧問、付款、留下資料時才要會員
- AI 教練只解釋報告與生活建議，不指定商品

## 客人怎麼走

```text
客人進入
    │
    ├─ 已有報告 ─ A App 拍照上傳 + AI
    │                 │
    │                 ├─ 選「一般」或「高級」
    │                 ├─ 在 A 金流付款
    │                 └─ 成功 → A App 預約，名單給 Y
    │
    └─ 沒有報告 ─ A App 說明要採檢
                      │
                      ├─ 選「中階」或「高級」
                      ├─ 在 A 金流先付款
                      └─ 成功 → Y 安排採檢 → 等報告 → Y 諮詢
```

金流成功才解鎖 Y。客人只付給 A。Y 諮詢內容 A 看不到。

## 三個方案

| 方案 | 誰買 | 付完得到什麼 |
| --- | --- | --- |
| 一般「報告解讀」 | 已有紙本血檢 | 一次 Y 真人解讀 |
| 中階「協助採檢」 | 沒報告、要驗血 | Y 安排採檢，回來再解讀 |
| 高級「個人化選品」 | 要顧問選品並出貨 | 諮詢 + KEY IN 出貨 |

有報告可選一般或高級；沒報告可選中階或高級。

## 之後才做（不要當客人端第一週範圍）

- Y：諮詢、安排採檢、KEY IN、出貨、簽核
- A 後台：出貨與費用、分潤 Dashboard
- MVP1 引擎／CRM、MVP2 專家訓練、MVP3 Terra／OCR profiling
